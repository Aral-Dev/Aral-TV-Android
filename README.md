# 📺 Aral TV — اپ اندروید (نسخهٔ ۱.۷.۱)

اپ اندروید **Aral TV** بر پایهٔ پوستهٔ موبایل خودِ سایت (Aral TV v1.7.0).

> **فلسفهٔ این نسخه:** سایت شما خودش یک اپ موبایل کامل است — نوار پایین ۵ تبی،
> جستجو در نوار بالا، تم دارک/لایت و چیدمان اپ‌گونه. این اپ یک **قاب تمیزِ نامرئی**
> است دور همان سایت: ظاهر سایت یک‌به‌یک و بدون هیچ دخالتی نمایش داده می‌شود؛
> اندروید فقط زیرساخت را اضافه می‌کند (نوارهای سیستم هماهنگ با تم، تمام‌صفحه،
> دانلود، اشتراک لینک و…).

## 🔧 تغییرات ۱.۷.۱ (هات‌فیکس)

- **رفع کرش هنگام باز شدن اپ** — در نسخهٔ ۱.۷.۰ ویوی تزئینی `BlobsView` (لکه‌های
  رنگی صفحهٔ ورود) فاقد constructor دوتایی `(Context, AttributeSet)` بود؛ اندروید
  موقع تزریق از XML به آن نیاز دارد و همین باعث `InflateException` و پیام
  «متأسفانه Aral TV متوقف شده» در همان لحظهٔ باز شدن می‌شد. هر سه constructor
  لازم اضافه شد.
- **CrashGuard** — اگر روزی خطایی رخ دهد، گزارش کامل آن در فایل
  `Android/data/com.araldev.araltv/files/last_crash.txt` ذخیره می‌شود تا مشکل
  از راه دور قابل تشخیص باشد.
- **مقاوم‌سازی** — مسیر ورود به اپ (اسپلش → مسیریابی) و استایل‌دهی صفحهٔ اتصال
  تضمین‌شده اجرا می‌شوند؛ خطای تزئینی هرگز ورود را مسدود نمی‌کند.

## 🔧 تغییرات ۱.۷.۲ (رفع کرش و قفل شدن اپ)

- **حلقهٔ کرش شکسته شد** — قبلاً آدرس پنل ذخیره می‌شد و اگر MainActivity کرش می‌کرد، هر اجرای بعدی
  مستقیم به همان صفحه می‌رفت و اپ برای همیشه قفل می‌شد. حالا `BootGuard` اجراهای ناموفق پیاپی را
  می‌شمارد و بعد از ۲ بار، به‌جای کرش، صفحهٔ تنظیم آدرس را (با پیام) باز می‌کند.
- **MainActivity محافظت‌شده** — هر خطای راه‌اندازی در `last_crash.txt` ثبت و کاربر به صفحهٔ تنظیم هدایت می‌شود.
  بخش‌های ظاهری (برند، رنگ نوارها، User-Agent، کوکی) جدا try/catch شدند.
- **`allowBackup=false`** — پس از حذف و نصب مجدد، آدرس خراب/قدیمی از بکاپ اندروید برنمی‌گردد.
- **کرش رندرر وب‌ویو** همیشه مدیریت می‌شود (قبلاً در حالت false کل اپ بسته می‌شد).
- پاک‌سازی null-safety در `onDestroy` / `onBackPressed` و کلید Go کیبورد در صفحهٔ اتصال.
- گزارش کرش حالا مدل گوشی و نسخهٔ اندروید را هم دارد.

### ساخت APK بدون نصب چیزی (GitHub Actions)
پوشهٔ پروژه را در یک مخزن گیت‌هاب آپلود کنید → تب **Actions** → «Build APK» → Run workflow →
فایل APK در بخش Artifacts دانلود می‌شود.

## ✨ چه چیزی اپ اضافه می‌کند؟ (فقط پشت‌صحنه)

- 🌓 **هماهنگی رنگ نوارها با تم سایت** — با هر تغییر تم در سایت، نوار وضعیت و
  نوار پایین اندروید همان رنگ لحظه‌ای سایت را می‌گیرند (دارک `#070707` / لایت `#f4faf6`)
  و جهت آیکون‌های سیستم هم تنظیم می‌شود
- 🔗 **اتصال به پنل** — اولین اجرا: آدرس ورکر را وارد می‌کنید؛ اعتبارسنجی با `/api/status`
- 🤝 **اشتراک/باز کردن لینک یوتیوب و آپارات** — لینک را از هر اپی Share کنید یا لمس کنید؛
  بعد از ورود، مستقیم همان ویدیو در پنل باز می‌شود
- ⛶ **ویدیوی تمام‌صفحه** — پلیر سایت در تمام‌صفحهٔ لنداسکیپ + ایمرسیو اجرا می‌شود
- 💾 **دانلود‌ها** — بکاپ JSON و فایل‌ها در پوشهٔ Downloads ذخیره می‌شوند؛
  بازیابی بکاپ با انتخابگر فایل نیتیو
- ⬅️ **دکمهٔ برگشت** — تاریخچهٔ صفحات → خروج با دو بار فشردن
- 🍪 **نشست پایدار** — کوکی‌ها بین اجراها حفظ می‌شوند؛ ورود گوگل داخل اپ کامل می‌شود

## 🚫 چه چیزی عمداً وجود ندارد؟

هیچ نوار ناوبری نیتیو، هیچ جستجوی نیتیو، هیچ CSS تزریقی نیست. `assets/bridge.js`
فقط سه کار پشت‌صحنه انجام می‌دهد (گزارش تم، نگه‌داشتن Blob ها برای دانلود،
باز کردن مسیر در انتظار بعد از ورود) و **هیچ استایلی به سایت اضافه یا کم نمی‌کند**.

## 🎨 برندینگ — همه‌چیز از خود سایت

لوگوی اسپلش/اتصال همان آیکون PWA سایت است؛ آیکون لانچر از همان آیکون سایت
ساخته شده؛ فونت‌ها (Vazirmatn · Orbitron · JetBrains Mono) همان فایل‌های فونت سایت
(تبدیل woff2 به ttf)؛ پالت رنگ همان دیزاین‌سیستم (`--fire`، `--neon`، `--bg`…) و
گوشه‌های بریدهٔ کارت‌ها همان clip-path سایت.

2. آدرس پنل را وارد کنید و «اتصال و ورود» را بزنید

## 🛠 بیلد از سورس

### روش ۱: Android Studio
پروژه را باز کنید و `Run` بزنید (Gradle 7.6.4 / AGP 7.4.2 خودکار دانلود می‌شوند).

### روش ۲: خط فرمان
```bash
cd AralTV-Android
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

### روش ۳: بیلد دستی بدون Gradle
```bash
export ANDROID_HOME=/path/to/android-sdk    # platform-35 + build-tools;35.0.0
bash tools/build-apk-manual.sh
# خروجی: dist/AralTV-v1.7.1.apk
```

## 📂 ساختار

```
app/src/main/
├── AndroidManifest.xml          ← فعالیت‌ها + فیلترهای لینک یوتیوب/آپارات
├── java/com/araldev/araltv/
│   ├── SplashActivity.java      ← اسپلش برندینگ سایت (مسیریابی تضمین‌شده)
│   ├── SetupActivity.java       ← اتصال به پنل (به زبان طراحی صفحهٔ ورود سایت)
│   ├── MainActivity.java        ← قاب WebView + تم + تمام‌صفحه + دانلود + اینتنت‌ها
│   ├── JsBridge.java            ← onTheme (رنگ نوارها) + saveFile (blob)
│   ├── CrashGuard.java          ← ثبت لاگ هر خطای احتمالی در فایل
│   ├── Ui.java                  ← پالت/فونت سایت + گوشهٔ بریدهٔ ARAL
│   └── BlobsView.java           ← لکه‌های fire/neon صفحهٔ ورود (+ constructor های XML)
├── assets/
│   ├── bridge.js                ← پل نامرئی (بدون هیچ CSS)
│   └── fonts/                   ← همان فونت‌های سایت (Vazirmatn/Orbitron/JetBrains)
└── res/                         ← آیکون لانچر از آیکون PWA سایت
```
