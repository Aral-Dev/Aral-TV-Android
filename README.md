# 📺 Aral TV — اپ اندروید (نسخهٔ ۱.۷.۲)

اپ اندروید **Aral TV** بر پایهٔ پوستهٔ موبایل خودِ سایت (Aral TV v1.7.0).

> **فلسفهٔ این نسخه:** سایت شما خودش یک اپ موبایل کامل است — نوار پایین ۵ تبی،
> جستجو در نوار بالا، تم دارک/لایت و چیدمان اپ‌گونه. این اپ یک **قاب تمیزِ نامرئی**
> است دور همان سایت: ظاهر سایت یک‌به‌یک و بدون هیچ دخالتی نمایش داده می‌شود؛
> اندروید فقط زیرساخت را اضافه می‌کند (نوارهای سیستم هماهنگ با تم، تمام‌صفحه،
> دانلود، اشتراک لینک و…).

## 🔧 تغییرات ۱.۷.۲ (رفع باگ اصلی کرش)

- **رفع کرش بعد از صفحهٔ اتصال** — ریشهٔ واقعی مشکل پیدا شد: در برندینگِ
  «Aral **TV**» (رنگ نارنجی « TV») بازهٔ span اشتباه بود: `setSpan(…, 5, 8, …)`
  روی رشتهٔ ۷کاراکتری `"Aral TV"` — انتهای ۸ از طول ۷ گذشته و
  `IndexOutOfBoundsException` می‌داد. در نسخهٔ ۱.۷.۱ این خط فقط در
  `MainActivity.styleBrand()` بدون محافظ بود → بعد از «اتصال و ورود» اپ بسته
  می‌شد و چون آدرس ذخیره شده بود، هر بار اجرا همینجا کرش می‌کرد (دقیقاً همان
  گزارش شما). بازهٔ درست `4 … 7` در هر سه صفحه (اسپلش/اتصال/برند خطا) اصلاح شد.
- **تور ایمنی چندلایه** — دیگر هیچ خطای تزئینی نمی‌تواند اپ را ببندد:
  - اگر لی‌اوت XML روی دستگاهی شکست بخورد، همان صفحه با ویجت‌های خالص ساخته می‌شود
    (`buildFallbackUi` / صفحهٔ متنی با سه دکمهٔ قابل استفاده به‌عنوان آخرین لایه)
  - کرش رندر وب‌ویو: بار اول بازآیایی تمیز؛ تکرارش زیر ۳۰ ثانیه → توقف حلقه و
    نمایش راه‌حل (تلاش دوباره / تغییر پنل / بازکردن در مرورگر)
  - رنگ نوارها، تمام‌صفحه و مصرف مسیر در انتظار همه در try-catch هستند
- **رفع باگ صفحهٔ اتصال** — قبلاً اگر setContentView شکست بخورد، همان خطا
  دوباره تکرار می‌شد؛ حالا به‌جایش رابط کاربری برنامه‌ای ساخته می‌شود

## ✨ چه چیزی اپ اضافه می‌کند؟ (فقط پشت‌صحنه)

- 🌓 **هماهنگی رنگ نوارها با تم سایت** — با هر تغییر تم در سایت، نوار وضعیت و
  نوار پایین اندروید همان رنگ لحظه‌ای سایت را می‌گیرند (دارک `#070707` / لایت `#f4faf6`)
- 🔗 **اتصال به پنل** — اولین اجرا: آدرس ورکر را وارد می‌کنید؛ اعتبارسنجی با `/api/status`
- 🤝 **اشتراک/باز کردن لینک یوتیوب و آپارات** — لینک را از هر اپی Share کنید یا لمس کنید؛
  بعد از ورود، مستقیم همان ویدیو در پنل باز می‌شود
- ⛶ **ویدیوی تمام‌صفحه** — پلیر سایت در تمام‌صفحهٔ لنداسکیپ + ایمرسیو اجرا می‌شود
- 💾 **دانلود‌ها** — بکاپ JSON و فایل‌ها در پوشهٔ Downloads ذخیره می‌شوند
- ⬅️ **دکمهٔ برگشت** — تاریخچهٔ صفحات → خروج با دو بار فشردن
- 🍪 **نشست پایدار** — کوکی‌ها بین اجراها حفظ می‌شوند

## 🧪 تست واقعی (خواستهٔ شما)

این نسخه روی **فریم‌ورک واقعی اندروید (سطح API 34)** اجرا و تست شد — نه فقط
بیلد. سناریوی دقیق خود شما شبیه‌سازی شد: اجرای سرد → اسپلش → صفحهٔ ورود آدرس →
وصل‌شدن با HTTP واقعی → ورود به اپ اصلی با وب‌ویو. **۷/۷ تست سبز** ✔
(اسپلش و مسیریابی، رندر صفحهٔ اتصال، جریان اتصال واقعی، ساخت قاب وب‌ویو،
پیام تم از پل، دکمهٔ برگشت، تشخیص منابع). در همین تست بود که باگ span پیدا شد.

## 🚫 چه چیزی عمداً وجود ندارد؟

هیچ نوار ناوبری نیتیو، هیچ جستجوی نیتیو، هیچ CSS تزریقی نیست. `assets/bridge.js`
فقط سه کار پشت‌صحنه انجام می‌دهد (گزارش تم، نگه‌داشتن Blob ها برای دانلود،
باز کردن مسیر در انتظار بعد از ورود) و **هیچ استایلی به سایت اضافه یا کم نمی‌کند**.

## 🎨 برندینگ — همه‌چیز از خود سایت

لوگوی اسپلش/اتصال همان آیکون PWA سایت است؛ فونت‌ها (Vazirmatn · Orbitron ·
JetBrains Mono) همان فایل‌های فونت سایت؛ پالت رنگ همان دیزاین‌سیستم و گوشه‌های
بریدهٔ کارت‌ها همان clip-path سایت.

## 🚀 نصب APK

`AralTV-v1.7.2.apk` را روی گوشی نصب کنید (اجازهٔ «نصب از منابع ناشناس» لازم است).
اگر نسخهٔ قبلی نصب داشته‌اید، همین‌طور روی آن نصب کنید — امضا یکی است و داده‌ها می‌مانند.
**اگر ۱.۷.۰/۱.۷.۱ نصب دارید و موقع باز شدن کرش می‌کرد، اول یک‌بار «Clear data» بزنید** تا
آدرس ذخیره‌شدهٔ قبلی پاک شود، بعد آدرس ورکر را دوباره وارد کنید (لازم نیست پاک کنید —
همین نسخه با آدرس قبلی هم بالا می‌آید).

1. اپ را باز کنید
2. آدرس پنل را وارد کنید و «اتصال و ورود» را بزنید
3. رمز عبور پنل را در صفحهٔ ورودِ خود سایت وارد کنید — تمام

## 🛠 بیلد از سورس

### روش ۱: Android Studio
پروژه را باز کنید و `Run` بزنید (Gradle 7.6.4 / AGP 7.4.2 خودکار دانلود می‌شوند).

### روش ۲: خط فرمان
```bash
cd AralTV-Android
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

### روش ۳: بیلد دستی بدون Gradle
```bash
export ANDROID_HOME=/path/to/android-sdk    # platform-35 + build-tools;35.0.0
bash tools/build-apk-manual.sh
# خروجی: dist/AralTV-v1.7.2.apk
```

## 🔑 امضا
`keystore/araltv-release.jks` (رمز `araltv2024`، alias `araltv`). برای انتشار عمومی
keystore خودتان را بسازید و رمز را مخفی نگه دارید.
